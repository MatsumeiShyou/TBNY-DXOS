# ディレクトリ・コンテキスト誤認防止プロトコル (Monorepo Guard)

## 1. 発生したインシデント
2026-04-19: エージェントが上位ディレクトリ (`TBNY DXOS`) において `git push` を実行し、正常終了したと誤認。実際には下位の `RePaper Route` フォルダ内に 26 件の重要な未プッシュの変更が残置されていた。

## 2. 再発防止プロトコル（AGENTS.md への追加推奨事項）
エージェントは、ソース管理操作（Git Add/Commit/Push）或いはビルド・デプロイ操作を行う際、必ず以下の手順を「物理的」に踏まなければならない。

1. **CWD 明確化**: `pwd` (PowerShell では `Get-Location`) を明示的に実行し、対象プロジェクトの「深さ」を自覚せよ。
2. **階層的ステータス監査**:
   - 上位ディレクトリで `git status` を実行するだけで満足するな。
   - `RePaper Route/` などの各サブプロジェクト内に入り、個別に `git status` を実行して「取り残された変更」がないことを 100% 証明せよ。
3. **視覚的証拠の提示**: プッシュ後、VS Code 等の Git 管理パネル（Source Control）が **「0 (ゼロ)」** になっていることを、システムメッセージまたはブラウザの目視、或いは `git status --porcelain` などのコマンドで「無（空）」であることを確認し、それをユーザーに報告せよ。

## 3. 禁止事項
- `git status` の出力が 0 行でない状態での「完遂報告」は、統治違反とする。
