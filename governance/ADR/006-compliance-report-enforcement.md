# ADR 006: Governance Compliance Report Enforcement (統治コンプライアンス報告の物理強制)

## Status
Accepted

## Context
AGENTS.md（v11.0時点）において、歩幅の制限や自己批判、記憶の外部化などのプロトコルが導入されたが、最終的な完了報告の際に「AIエージェントがすべてのルールに則って実装を行ったか」を明示的にユーザーへ伝えるプロセスがシステム的に担保されていなかった。
ユーザーより「すべての実装後にAGENTS.mdに則して実装を行ったことを毎回報告する義務を課し、それを物理強制してほしい」という要求があった。

AIのテキスト生成内容（対話）そのものをスクリプトで完全にコントロールすることは難しいが、「報告のためのレポートファイル」の作成を物理的に義務付けることは可能である。

## Decision
最高憲法 `AGENTS.md` v12.0 として、以下のルールと物理強制を導入する。

### 1. [Governance Compliance Report (統治遵守報告の義務)]
- **ルール**: 実装完了後、報告の直前に必ず `.agent/scratch/compliance_report.md` を作成し、AGENTS.mdに規定された主要プロトコルの遵守状況を自己点検せよ。
  また、完了報告（SDR）を行う際は、必ずこのレポートの内容（チェックリスト）をユーザーに提示せよ。
  レポート内には `[COMPLIANCE_CLEARED]` の明記を必須とする。
- **物理強制**: `done.js`（完了前監査）にて、同ファイルの存在と `[COMPLIANCE_CLEARED]` 文字列の有無をチェックし、満たさない場合は GSEAL（完了証明）の発行をブロックする。

## Consequences
- **Positive:**
  - AIが自身の行動を統治ルールと照らし合わせる「総括プロセス」が強制され、遵守率がさらに高まる。
  - ユーザーは、毎回「どのルールがどのように守られたか」を客観的なレポートとして確認できるため、安心感・透明性が向上する。
- **Negative:**
  - 完了報告の手間（ファイル作成と報告テキストの量）がさらに増える。しかし、本プロジェクトの「スピード度外視・精度優先」方針においては許容されるトレードオフである。
