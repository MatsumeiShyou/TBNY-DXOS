# ADR 002: Seal Protocol Physical Interlock (完了アナウンスの物理強制)

## Date
2026-05-24

## Status
Accepted

## Context
AIが作業を完了した際、AGENTS.md にルールが存在するにもかかわらず、「承認の入力（y）と `npm run done` の実行を人間に促すアナウンス」を失念し、システムが自動進行しなくなる（人間のアクション漏れを誘発する）問題が発生した。LLMの文脈理解に依存するソフト・ルールでは再発のリスクがあるため、物理的なインターロック（遮断機構）が必要であると判断した。

## Decision
1. **アナウンス用コマンドの導入**: AIは完了報告の直前に必ず `npm run request-done` を実行する。このコマンドはコンソールに「HUMAN ACTION REQUIRED」として承認手順を出力し、同時にロックファイル（`.agent/session/.seal_requested`）を生成する。
2. **完了コマンドへのインターロック追加**: `npm run done` 内の `closure_gate.js` 冒頭にて、上記のロックファイルの存在チェックを行う。存在しない場合（＝AIが事前アナウンスをサボった場合）、直ちにエラーとしてプロセスを終了させる。

## Consequences
- **Positive**: 
  - AIのアナウンス漏れがシステムレベルで物理的にブロック（Prevent）される。
  - 人間へのコールトゥアクションがより明確かつ強固になる。
- **Negative**:
  - `npm run done` の実行前条件が1つ増えるため、手動でテストやデバッグを行う際にも必ずフラグファイルの生成が必要になる（もしくはエラーメッセージに従う必要がある）。
