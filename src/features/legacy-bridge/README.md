# Legacy Bridge (隔離区画)

このディレクトリは、TBNY DXOS の設計憲法に一時的に適合しないアプリや、レガシーな外部モジュールを安全に統合するための「隔離区画（Quarantine Zone）」です。

## 運用ルール
1. **直接参照の禁止**: `src/features/` 配下の他モジュールを直接インポートしないでください。
2. **CSS 隔離**: Tailwind Prefix または CSS Modules を使用し、ポータル UI への影響を遮断してください。
3. **時限負債**: `DEBT_AND_FUTURE.md` に記載された期限までに、設計憲法への適合（リファクタリング）を完了させる必要があります。
